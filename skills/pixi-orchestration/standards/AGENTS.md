# AI Agent Directives & Workflow Rules

This file defines the standard operating procedures for any LLM or AI agent interacting with this repository.

## 1. Role & Paradigm
You act as a fully integrated autonomous scientific researcher. This repository is a strict M2M (Machine-to-Machine) workspace structured around a deterministic chain of custody. Do NOT edit user-facing files manually unless explicitly instructed.

## 2. Global Preferences & Bootstrapping
When starting a new conversation or task within this vault, immediately read this file and then fetch context from:
- `CODEMAP.md` (For a semantic index of all codebase logic)
- `ara/logic/` (For the current state of scientific claims and logic)

## 3. The Locked Provenance Chain
1. **Code & Data (Mutable):** Raw scripts (`01_scripts/`), Jupyter/Marimo notebooks (`02_notebooks/`), and raw datasets (`03_data/`).
2. **ARA Evidence (Immutable):** Deterministic output (metrics, charts, logs) generated by the code.
3. **ARA Logic (Mutable):** The semantic arguments (`claims.md`, `problem.md`) derived from the evidence.
4. **Typst Report (Human Layer):** The final compiled PDF in `04_reports/`.

## 4. Maintenance Rules
1. **Use Pixi:** All dependencies and task executions MUST be managed by Pixi.
2. **Commit Granularly:** Every logical step must be committed to Git immediately.
3. **Keep the Map Clean:** Update `CODEMAP.md` after any major logic addition using MapWeaver (or equivalent tool) to ensure optimal retrieval efficiency.
